# 💰 Personal Financial Dashboard

A full-stack web application built during my internship at **Career Credentials** to help users manage personal finances — including income, expenses, budgets, and investments.

## 🧠 Overview

The Personal Financial Dashboard offers a responsive and interactive interface to help individuals monitor their financial data. It features secure login, dynamic data handling, and RESTful API communication, with both frontend and backend components.

---

## ✨ Features

- 📊 Interactive dashboard to monitor income, expenses, and investments
- 🔐 User authentication and session management
- 🗂️ Expense categorization and budget planning
- 📡 RESTful APIs for dynamic data operations
- 🌐 Fully responsive UI
- 🧠 Some pages built using EJS templates for server-side rendering

---

## 🛠️ Tech Stack

| Frontend | Backend         | Database | Server-Side Templating |
|----------|------------------|----------|--------------------------|
